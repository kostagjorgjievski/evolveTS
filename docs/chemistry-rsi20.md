# Crossed-seed full-task chemistry RSI pilot

Four branches cross Kimi3.1pro medium and BigModel GLM5.3 max with two frozen
verified chemistry seeds: single-group THC4.146047 and grouped/source-built
radix4 compiler3.569539. Three fresh conversations per branch,1200seconds of
model development after provider admission each, twelve scored E0 nodes total.
This is a separate labelled pilot; the old user-stopped chemistry campaign and
user-paused DQI RSI campaign are not resumed or altered.

`short_chemistry_rsi.py` connects these isolated workers to the existing upstream
DreamRSI engine. Branches advance independently after their own full grading.
Own experimental memory and full source/data helpers carry forward; no other
branch's live discoveries or transcripts enter a conversation. Hermes context is
frozen for this level. Actual model/effort metadata, provider admission and SDK
traces remain in each worker's private directory. Existing provider capacities
and shared CPU validation admission remain unchanged.

`short_chemistry_tools.py` preserves task diagnostics and public research tools;
a full-validation tool request freezes a hash manifest and asks the model to
finish. The controller performs unchanged full development validation and an
independent salt on the identical saved submission outside the model clock.
A rejected scientific candidate is archived and its own verified parent restored
and checked. Missing model/MCP startup blocks recovery rather than counting a
baseline round. All original official normalization and task limits remain.

After all12 nodes complete, the supervisor invokes actual upstream policy
discovery (three rewrites, one retry batch) with native Codex GPT-6.1-Sol medium
and replay, promoting only through the existing qualified-policy gate. It stops
after E0+dreaming; no automatic E1 or Kaggle submission is authorized. Separate
Hermes researchers continue using their independently authorized budgets.
